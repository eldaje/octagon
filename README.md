# OCTAGON

Eight enter. One verdict. Models compete on images, code and argument —
blind-ranked by their peers, then chaired. By [ALAB](https://github.com/eldaje).

**Live:** https://octagon.wtf

## Bouts

- **Debate** — the classic MOTM flow: independent answers, blind peer review, Borda tally, chair.
- **Image** — the same brief goes to every seated image model; renders come back side by side, vision models judge blind, the crown goes to the top Borda score. Attach a reference image to steer style-ref contestants.
- **Code** — contestants deliver working files (FILE: blocks). Preview HTML entries live in a sandboxed frame, download any entry as a zip.

## Attachments

Images (incl. HEIC — converted in-browser), video (MP4/MOV to video-capable models), PDF, DOCX, XLSX (all extracted client-side), and plain text. Files never touch a server: everything runs in your browser against the Venice API with your own key.

## Notes

- Single self-contained HTML file. No build step.
- Forked from [MOTM](https://motm.wtf) — separate repo, separate domain, separate storage. They never touch.
